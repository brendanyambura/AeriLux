# Modern To-Do List App

A colorful, modern Android To-Do List application built using Java and Material Design components.

## Features
- **Modern UI**: Bright colors, rounded cards, and smooth layouts.
- **Task Management**: Add, edit, delete, and complete tasks.
- **Data Persistence**: Tasks are saved automatically using `SharedPreferences` and `JSONArray`.
- **Search**: Quickly find tasks using the search bar.
- **Priority Indicators**: Color-coded badges for High, Medium, and Low priorities.
- **Progress Tracking**: Visual progress bar for completed tasks.
- **Motivational Quotes**: Daily inspiration to keep you productive.
- **Swipe to Delete**: Intuitive swipe gestures with Undo capability.
- **Auto-sorting**: Completed tasks move to the bottom of the list.

## Technologies Used
- Language: Java
- UI: XML with Material Design 3
- Data: SharedPreferences, JSON
- Components: RecyclerView, ConstraintLayout, MaterialCardView, FloatingActionButton

## Setup Instructions
1. Clone the repository.
2. Open the project in Android Studio (Koala or later recommended).
3. Ensure you have the Android SDK for API 34+ installed.
4. Build and run the app on an emulator or physical device.
